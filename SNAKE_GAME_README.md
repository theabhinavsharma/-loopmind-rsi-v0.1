# Snake '95 - Classic 90s Style Snake Game

A retro-styled Snake game built with HTML5 Canvas and JavaScript, featuring authentic 90s aesthetics including:

- **Classic green monochrome CRT monitor look**
- **Pixel-perfect graphics with scan line effects**
- **Retro pixel font (Press Start 2P)**
- **Glowing borders and text effects**
- **Local high score storage**

## How to Play

1. Open `snake_game.html` in any modern web browser
2. Press any **Arrow Key** to start the game
3. Use **Arrow Keys** to control the snake:
   - ⬆️ Up Arrow - Move Up
   - ⬇️ Down Arrow - Move Down
   - ⬅️ Left Arrow - Move Left
   - ➡️ Right Arrow - Move Right
4. Press **Spacebar** to pause/unpause the game
5. Eat the red food squares to grow your snake and increase your score
6. Avoid hitting the walls or your own tail!

## Game Features

- **Score System**: Gain 10 points for each food item eaten
- **High Score**: Your best score is automatically saved locally
- **Snake Length Counter**: Track how long your snake grows
- **Game Over Screen**: Shows final stats and restart option
- **Pause Functionality**: Press space to pause mid-game
- **Authentic 90s Speed**: Perfectly balanced game speed for classic feel

## Running the Game

Simply double-click `snake_game.html` or open it in your web browser. No additional setup or installation required!

## Browser Compatibility

Works in all modern browsers including:
- Chrome
- Firefox
- Safari
- Edge

## Tips for High Scores

- Plan your path ahead to avoid getting trapped
- Try to keep the snake moving in large loops
- Don't rush - the 90s speed is perfect for strategic play
- Use the pause feature (spacebar) to plan difficult moves
